# KLP Show — Landing Page

Landing page moderna, responsiva e de alta performance desenvolvida com **React 19**, **Vite** e **Tailwind CSS v4**.

## Como rodar o projeto

1. Instalar as dependências:
   ```bash
   npm install
   ```

2. Iniciar o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Gerar a build de produção:
   ```bash
   npm run build
   ```

## Estrutura do Projeto

- `src/main.tsx` — Ponto de entrada do React
- `src/App.tsx` — Componente principal da landing page da banda
- `src/index.css` — Estilos globais e importação do Tailwind CSS v4
- `index.html` — Shell HTML padrão do Vite
- `package.json` — Dependências e scripts
- `vite.config.ts` — Configuração limpa do Vite com React e Tailwind CSS
